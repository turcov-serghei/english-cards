# Карточки: английский и румынский — память проекта

## О проекте
- Приложение-карточки для детей (1–12 класс): английский и румынский, картинки (эмодзи), транскрипция IPA и русскими буквами, режим «Учить», тесты (4 варианта, несколько видов вопросов), профили учеников с историей (localStorage). Автор — родитель, общается по-русски.
- Файлы: `index.html` (код), `words.js` (словарь, 1032 слова, из них 214 в теме «Глаголы»), `anim.js` (анимации действий), `audio_ro.js` (румынская озвучка Piper «Liana», CC BY-NC 4.0), `english-cards.html` (сборка одним файлом: `node tools/build.js`), `tools/merge.js` (добавление слов), `tools/fix.js`, `tools/merge_ro.js`. Документы: README.md, DEPLOY.md, BACKUP.md, NEXT_STEPS.md, PROMPTS.md.
- Сайт: https://turcov-serghei.github.io/english-cards/ (GitHub Pages, ветка main, публикуется автоматически после push).
- Черновая версия для показа — артефакт Claude: https://claude.ai/artifact/8pZ4i3aam8G4f3P9A1uv3Z (slug 3f53b01a-9a51-4ea1-8f80-812e0de196c8), публикуется файлом english-cards.html как index.html.

## Правила работы (просьбы автора)
- Для простых задач использовать Haiku (субагенты).
- Изменения приложения сначала показывать в артефакте Claude; в main/GitHub отправлять только после «да» автора. Черновики — в отдельной ветке.
- Голос Claude и диктовка Claude выключены — не включать.
- Экономить токены и размер приложения: автор НЕ хочет встраивать записанную английскую озвучку (файл вырастет ~на 5 МБ). Голоса браузера + скачиваемый нейроголос.
- Тест: после неправильного ответа всегда произносить правильное слово; после правильного — только если слово не звучало в вопросе (`T.spoke`).
- Класс всегда включает все младшие классы. На плашках классов: у выбранного — число слов, у остальных — разница (+/−).
- Глаголы: эмодзи у них только подсказка с подписью «глагол»; в тестах для глаголов только текстовые вопросы.

## Что сделано в последней сессии (14.11.2026) — всё в main и на сайте

В артефакте Claude не работает (загрузки запрещены) — проверять на сайте. Новое слово готовится 1–4 с.

Просмотры в «Учить» пишутся в `STATS[key].seen`.
- Документы: BACKUP.md (резервная копия), DEPLOY.md, NEXT_STEPS.md, этот файл.

## Известные проблемы (не решены)
- **Румынские слова звучат отвратительно** на части слов. «🎧 Записанное произношение» — это заранее сгенерированные Piper «Liana» MP3 (по одному на слово, `audio_ro.js`); модель ошибается в ударениях и гласных из-за слабого словаря eSpeak. Варианты: автор даёт список плохих слов → переозвучить с подсказкой ударения/другим написанием; румынский нейроголос в браузере (Piper WASM); голос устройства для таких слов. Kokoro румынский не поддерживает.
- **Распознавание речи (voice recognition) работает плохо**, особенно румынский; Whisper-режим ни разу не проверен целиком; «Запиши и сравни» не проверен на реальном микрофоне.
- Подробный список задач — NEXT_STEPS.md.

## Идеи по озвучке через JS (не делать без согласия автора)
- (Английский уже сделан на Kokoro.) Нейросетевой TTS прямо в браузере (модель скачивается один раз и кешируется браузером, приложение не растёт): Piper в WebAssembly (piper-tts-web / vits-web, sherpa-onnx wasm) — есть английские и румынские голоса; Kokoro.js (только английский, хорошее качество, модель ~80 МБ). Проверить лицензии голосов.
- meSpeak.js / eSpeak-ng — маленькие, но звучат роботом.
- Голос Google Translate — неофициальный доступ, может блокироваться, нарушает правила Google — не использовать.
- Облачные TTS (Google Cloud, Azure) — нужен ключ, на открытом сайте его увидят все — не подходит.

## Как продолжить в новой сессии
1. Прочитать этот файл и NEXT_STEPS.md; `git log --oneline -10`.
2. Правки — в отдельной ветке → `node tools/build.js` → проверить Playwright-тестом (Chromium установлен) → опубликовать english-cards.html в артефакт (slug выше) → после «да» автора влить в main и `git push origin main` (Pages обновится за ~1 мин).
3. Отвечать автору по-русски, кратко; простые задачи — Haiku.
