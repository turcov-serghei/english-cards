# Карточки: английский и румынский

Приложение для детей (1–12 класс) для изучения слов английского и румынского языка: карточки с картинками, произношение, транскрипция, тесты, профили учеников и история результатов.

Всё работает в браузере, без сервера и без интернета: откройте `english-cards.html` (один файл, всё встроено).

## Возможности

- ~820 слов (существительные, цвета, числа, действия, предлоги), темы, классы 1–12 (класс включает все предыдущие).
- Английский: транскрипция [IPA] и русскими буквами, голос устройства.
- Румынский: перевод, чтение русскими буквами, встроенная озвучка всех слов (нейросетевой голос Piper «Liana»).
- Режим «Учить»: карточки, озвучка, медленное произношение, опционально — «Запиши и сравни», Whisper или распознавание браузера.
- Тест: 15/30/50/100/все вопросов, несколько видов вопросов вперемешку, звуки, проходной балл (по умолчанию 80%), повторение ошибок.
- Ученики (без паролей): имя, возраст, класс; у каждого свои результаты, статистика и настройки. Резервная копия — кодом.
- Анимированные действия (Noto Animated Emoji), предлоги — нарисованные схемы (SVG).

## Структура

| Файл | Что это |
|---|---|
| `index.html` | исходный код приложения (HTML/CSS/JS) |
| `words.js` | словарь: `en` (id), `ru`, `ro`, `img` (эмодзи, ссылка или `svg:<предлог>`), `tr`, `trRu`, `roRu`, `cat`, `lvl` |
| `anim.js` | анимированные картинки для действий (WebP в base64) |
| `audio_ro.js` | озвучка румынских слов (MP3 в base64) |
| `english-cards.html` | собранная версия — один файл, всё встроено |
| `tools/build.js` | сборка `english-cards.html` |
| `tools/merge.js`, `tools/fix.js`, `tools/merge_ro.js` | добавление слов, правки словаря, румынские переводы |
| `PROMPTS.md` | запросы, по которым создавалось приложение |
| `DEPLOY.md` | публикация на GitHub Pages |
| `NEXT_STEPS.md` | что осталось сделать (next steps) |

Сборка: `node tools/build.js`

Добавить слова: дописать строки в `words.js` в том же формате и пересобрать, или в приложении — «➕ Мои слова».

## Работа без Claude

Приложение — обычная веб-страница. Оно не обращается к Claude и не тратит токены: обучение, тесты, озвучка и статистика выполняются в браузере. Файл можно открыть с компьютера/телефона, положить на любой хостинг (например, GitHub Pages).

Как выложить на GitHub Pages — см. [DEPLOY.md](DEPLOY.md).

Голос Claude и диктовка Claude отключены — приложение полностью работает без Claude.
