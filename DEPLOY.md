# Публикация на GitHub Pages

Приложение можно опубликовать как обычный сайт через GitHub Pages. Сайт работает без Claude, без токенов и без какого-либо сервера: вся логика выполняется в браузере.

## Что уже сделано в репозитории

- В корне есть пустой файл `.nojekyll`. Он говорит GitHub отдавать файлы как есть, без обработки Jekyll.
- `index.html` подгружает `words.js`, `anim.js` и `audio_ro.js` по относительным путям, поэтому работает на Pages без изменений.
- `english-cards.html` — сборка в один файл, где всё встроено. Её удобно открыть или переслать одним файлом.

## Однократная настройка (вручную, в браузере)

Окружение Claude не может включить Pages сам: его прокси блокирует GitHub Pages API (ошибка 403). Поэтому настройку нужно сделать вручную.

1. Откройте https://github.com/turcov-serghei/english-cards/settings/pages
2. В разделе «Build and deployment» → **Source** выберите «Deploy from a branch».
3. **Branch**: `main`, папка **/ (root)**, нажмите **Save**.
4. Подождите 1–2 минуты. Ссылка на сайт появится вверху этой же страницы. На вкладке **Actions** видно запуск «pages build and deployment».

## Адреса

- https://turcov-serghei.github.io/english-cards/ — `index.html`
- https://turcov-serghei.github.io/english-cards/english-cards.html — одна страница со всем встроенным

## Обновление сайта

1. Отредактируйте файлы (например, `words.js` или `index.html`).
2. Пересоберите одиночный файл: `node tools/build.js` (это обновит `english-cards.html`).
3. Сделайте коммит и отправьте его: `git commit` → `git push`.
4. GitHub Pages переопубликует сайт автоматически через 1–2 минуты.

На телефоне браузер может показывать старую версию из кеша. Обновите страницу (потяните вниз или перезагрузите вкладку).

## Альтернатива: через gh CLI с компьютера

Если на компьютере установлен `gh` и выполнен вход в аккаунт GitHub, Pages можно включить командой:

```bash
gh api -X POST repos/turcov-serghei/english-cards/pages -f 'source[branch]=main' -f 'source[path]=/'
```

## Важные замечания

- **Профили и результаты учеников** хранятся в `localStorage` каждого браузера отдельно и не синхронизируются между устройствами. Чтобы перенести профиль, используйте резервную копию кодом из приложения.
- **Микрофон и распознавание речи** работают только по HTTPS. GitHub Pages даёт HTTPS автоматически.
- **Румынский голос Liana** распространяется по лицензии CC BY-NC 4.0: только некоммерческое использование. Подробнее — в разделе «Лицензии» файла `README.md`.

## Проверка после включения

- [ ] Страница открывается по адресу `index.html` и по адресу `english-cards.html`.
- [ ] Английские слова произносятся голосом устройства.
- [ ] Румынские записанные озвучки («Liana») проигрываются.
- [ ] Тесты проходятся до конца, результаты сохраняются.
- [ ] Профиль ученика сохраняется после перезагрузки страницы.
- [ ] Сайт открывается и работает на телефоне.

## Если сайт не появился

Если Pages включён, но во вкладке **Actions** нет ни одной сборки «pages build and deployment» — сборка просто ещё ни разу не запускалась (она запускается при отправке изменений). Запустить можно пустым коммитом:

```bash
git commit --allow-empty -m "Trigger GitHub Pages build" && git push origin main
```

Через ~1 минуту в **Actions** появится сборка; зелёная галочка — сайт готов.

Блок «Visibility · GitHub Enterprise» в настройках Pages не нужен (это платное закрытие сайта от посторонних) — «Start free for 30 days» не нажимать.
